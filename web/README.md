2026-10-19 新增三轴长方体姿态：FFF2 独立 Notify，20 字节 `02` 帧，XYZ 为带符号的百分之一 m/s²，独立采样序号与有效位。原 FFF1 环境帧不变。新网页连接旧板端时只显示“未提供姿态通道”，环境数据显示继续工作。

姿态区显示扁长方体、正反面、XYZ 轴、三轴数值、横滚与俯仰；鼠标拖动观察、滚轮缩放，“恢复视角”只复位相机。数据独立超过 1.5 秒会灰显，不能由环境数据刷新延长有效期。按传感器 +X 为板头参考，实物轴向仍需现场核对。加速度计不能恢复航向或位移；近自由落体时角度无效，动态加速度提示是启发式，不代表精度认证。

渲染资源为本地托管的 Three.js r186，来源与 MIT 许可见 `dist/vendor/README.md` 和 `THREE-LICENSE.txt`。WebGL 不可用时仍可查看数值。已增加 `test_pose.mjs`，完整检查命令为 `node --test test_protocol.mjs test_connection.mjs test_app.mjs test_pose.mjs`。

入口为 `dist/index.html`，无 CDN、数据库或构建依赖。只从浏览器 BLE 接收设备数据，不将温湿度、光敏或历史曲线上传服务器。2026-10-18 按用户要求改为公开、免登录访问。电脑网页实收已由用户确认，安卓手机连接尚未验收。

使用安卓或电脑 Chrome，通过 HTTPS 打开页面，点击“连接设备”，选择 **UniKnect_V2**。浏览器连接 FFF0 服务并订阅 FFF1 Notify，显示温湿度、原始光敏值、暴露状态和最近 5 分钟曲线。收到有效通知之前不显示初始化值，不含演示数据。

超过 3 秒无新帧显示数据过期；断连保留灰色旧值，重新连接清空历史。保持前台使用，不承诺锁屏采集。第一次连接前断开 nRF Connect 等其他 BLE 客户端。设备配对不能替代网页里的连接。

本地桌面调试：从此目录执行 Python 的 `http.server 8765 --bind 127.0.0.1 --directory dist` 后打开 `http://localhost:8765`。手机应打开发布后的 HTTPS 地址；手机访问电脑普通局域网 HTTP 地址不满足 Web Bluetooth 的安全上下文要求。
